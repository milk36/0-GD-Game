1. 项目概述

定位：在 demo-game 游戏大厅中新增第一款可玩小游戏。从主菜单点击 「俄罗斯方块」进入游戏场景，Esc/按钮返回大厅。经典俄罗斯方块规则 + 赛博朋克霓虹视觉包装。

项目内容
玩法类型经典落块消除（Tetris Guideline 简化版）
视觉风格赛博朋克：深空蓝黑底、霓虹青/粉主色、扫描线、故障感消行动画
平台Godot 4.7.2 桌面端（GL Compatibility 渲染器）
目标版本M1 核心可玩 → M3 打磨完成，单场景交付

2.3 方块单元渲染风格

  • 每个格子：霓虹主色填充（略暗化 80%）+ 亮色描边（2px）+ 内部对角高光线，模拟霓虹灯管质感。
  • 发光实现：绘制多层半透明扩散描边（外扩 2/4/6px、透明度递减）， 不依赖 HDR/Bloom——项目使用 GL Compatibility 渲染器， 以 CanvasItem._draw() 多层绘制实现辉光，保证全平台一致。
  • 幽灵方块（Ghost）：仅描边 + 20% 透明填充，指示落点。

2.4 全屏氛围特效

  • 扫描线：全屏叠加层，每 4px 一条 3% 透明度暗线（一张可平铺纹理或 _draw 绘制）。
  • 背景网格：棋盘外背景绘制淡青色透视网格线（透明度 4%），营造数字空间感。
  • 消行动画：被消除行先闪白 → 霓虹色故障抖动（水平错位 + 随机色差）→ 碎裂消失，总时长约 0.25s。
  • 硬降特效：方块落地瞬间棋盘轻微向下震动 2-3px + 落点列拖尾光柱。
  • 升级特效：升级时边框霓虹色波纹扫过一次。

3. 游戏规则与机制

3.1 棋盘与方块

  • 棋盘 10 列 × 20 行（可视），另加顶部 2 行隐藏缓冲区，共 22 行。
  • 7 种标准方块（I/O/T/S/Z/J/L），采用 7-bag 随机器：每袋 7 种随机排序发完再补袋，保证分布均匀。
  • 出生位置：棋盘顶部居中（列 3-6 区域），出生即与已堆叠方块重叠 → 直接 Game Over。

6.4 渲染决策

为什么用 _draw() 自绘而不是 TileMap / 大量节点？ 棋盘最多 220 格 + 特效层，自绘一次 queue_redraw() 即可全量重画， 无节点开销；霓虹辉光需要多层半透明矩形，自绘最容易控制； 且 GL Compatibility 下不依赖 2D Glow 特性，表现稳定。

6.5 主菜单接入改造

# main_menu.gd
const GAME_SCENES := { "俄罗斯方块": "res://scenes/tetris.tscn" }

func _on_game_selected(game_name: String) -> void:
    if GAME_SCENES.has(game_name):
        get_tree().change_scene_to_file(GAME_SCENES[game_name])
    else:
        _status.text = "「%s」开发中，敬请期待~" % game_name

8. 验收标准

  • 从大厅点击「俄罗斯方块」进入游戏，Esc 可返回大厅（先弹暂停层）。
  • 7 种方块正确生成（7-bag）、可移动/旋转（含墙踢）/软降/硬降/Hold，幽灵方块指示落点。
  • 消行正确（1-4 行）、计分公式正确、每 10 行升级并加速。
  • 方块堆到顶部触发 Game Over，覆盖层显示成绩，可重开。
  • 锁定延迟与 DAS 生效；最高分重启后保留。
  • 视觉符合第 2 节规范；无报错、无脚本警告；窗口缩放布局不错位。
