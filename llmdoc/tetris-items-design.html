▚ 俄罗斯方块 · 道具系统与粒子特效 · 需求设计

在现有俄罗斯方块（见 tetris-design.html / tetris-game.html）基础上新增： 风 / 雨 / 雷电 三种随机道具与消除粒子特效。本文档为实现前的需求定义， 边界行为以「设计决策」形式显式固定；标 待确认 的条目可在评审后调整，不影响其余部分。

1. 道具获取机制 —— 「数据碎片格」

采用「数据碎片格」概念包装（赛博朋克语境：棋盘上随机出现一段加密数据， 在时限内将其"下载"即可获得道具）：

  1. 刷新：开局 15 秒后首次刷新，此后每隔 20 秒 刷新一次； 全局同一时刻棋盘上最多存在 1 个 碎片格，新刷出的覆盖旧的。
  2. 位置规则：从当前已有方块占据的格子中随机选取一格， 该格标记为碎片格（霓虹金色脉动描边 + 扫描动画）。 若刷新时刻棋盘无任何堆叠方块，则推迟到出现首个锁定块后的下一帧再选格。
  3. 获取判定：碎片格自带 15 秒 倒计时。 若在倒计时内该格子所处方块被消行带走（普通消行即可，1~4 行均可）， 判定获取成功；倒计时归零未消除则碎片格熄灭消失，等待下轮刷新。
  4. 道具分配：获取成功时，风 / 雨 / 雷 三选一等概率随机（各 1/3）， 弹出对应图标与名称反馈（WIND 风 / RAIN 雨 / BOLT 雷电）。
设计决策 D1（碎片格选取范围）：只选「已填充」格子。 理由：碎片格在空位上时玩家无法主动"消除该格"，只能被动等堆叠到达， 体验不可控；已填充格保证玩家始终可以通过消行主动争取。
设计决策 D2（道具使用方式）— 已确认：自动触发：获取道具后立即自动触发效果 （0.35s 预闪演出 → 执行清除），无道具槽、无释放按键。 消除目标不足（如风无可消行）时道具作废，浮字提示「数据丢失」。

2. 三种道具效果定义

道具主题色效果不足时行为
风 WIND #7ef9ff 浅青 横向随机消除 2 行：从「含至少 1 个方块的行」中随机选 2 行， 消除这两行的全部方块，上方整体下移（复用现有消行下落逻辑） 非空行不足 2 行时有几行消几行；无可消行则不消耗道具
雨 RAIN #4d7bff 亮蓝 从棋盘全部已填充格子中随机散点消除，最多 10 个（均匀随机、可分散任意位置） 已填充格子不足 10 个时全部消除；棋盘为空则不消耗道具
雷电 BOLT #ffe600 电光黄 竖向随机消除 2 列：从 10 列中随机选 2 列， 消除这两列的全部已填充方块（形成竖井） 两列均无方块时不消耗道具；仅一列有方块时仍消耗（消 1 列）
设计决策 D3（消除后的重力）：风消整行后上方下移（天然符合现有逻辑）； 雨与雷电消除后其余方块保持原位、不逐格下落，留下孔洞 / 竖井。 理由：俄罗斯方块锁定块本无重力，孔洞正是道具的战略价值（雷电清竖井、雨打洞）； 引入逐格重力会造成全盘连锁位移、破坏玩家布局预期且实现复杂。
设计决策 D4（计分与升级）— 待确认：道具消除不计入 LINES（不影响升级节奏）， 按「每消除 1 格 = 5 分 × 当前等级」给分（软降/硬降计分不变）。 理由：若计入 LINES，道具会大幅加速升级、破坏难度曲线。
设计决策 D5（释放时机）：道具在 PLAYING 与 CLEARING 状态可释放； 暂停 / Game Over 时不可。释放瞬间走独立的 0.35s 道具动画状态（期间方块重力暂停）， 动画结束后恢复。释放 不重置 当前块的锁定延迟计时。
设计决策 D6（碎片格与消行判定的原子性）：判定"碎片格被消行带走"以 board.remove_rows() 执行后的格子内容为准 —— 碎片格所在行被消即成功， 与该行是单消还是 Tetris 无关。道具（风）触发的整行消除同样可以带走碎片格（道具滚道具，允许）。

3. 粒子与视觉特效

3.1 消除粒子（核心需求）

  • 普通消行：现有 0.28s 故障闪光动画结束时，每个被消格子爆出 8~10 个粒子，颜色继承该格方块霓虹色，初速向外随机（50~180 px/s）， 带轻微重力（300 px/s²）与阻尼，寿命 0.4~0.7s，尺寸 2~4px，淡出消失。
  • 道具消除：同上，每格粒子数提升到 12~16 个并附加白色高亮粒子混合， 强化"被系统删除"的观感。
  • 性能：粒子为纯数据数组（pos/vel/color/life），由独立粒子层 _draw() 自绘，单帧峰值约 200×16 ≈ 3200 粒子上限保护（超限随机丢弃最旧）， 无节点创建开销。

3.2 道具专属特效

事件表现
碎片格出现金色方框从大缩到位（0.3s）+ 脉动描边 + 角落倒计时环
获取成功碎片格位置金色粒子爆发 + 右栏道具槽弹跳高亮 + 浮字「WIND/RAIN/BOLT 已捕获」
获取失败（超时）红色闪烁 2 次后熄灭，微弱红色粒子散逸
风释放被选中的 2 行先青色高亮 0.15s → 横向风痕扫过（左右两条速度线）→ 格子消除 + 粒子
雨释放被选中的散点格子逐个（间隔 30ms）蓝白闪现 → 消除 + 向下坠落的拖尾粒子（模拟雨滴）
雷电释放被选中的 2 列顶部到底部电光（锯齿折线，0.2s）→ 列闪白 → 消除 + 黄白电弧粒子

3.3 HUD 变更

  • 无道具槽（自动触发）；获取反馈改为棋盘上方浮字： 「⌁ WIND · 风已注入」「☂ RAIN · 雨已注入」「⚡ BOLT · 雷已注入」， 道具色渐隐 1.2s。
  • 目标不足作废时浮字「数据丢失…」灰色。

4. 输入与配置

本需求无新增按键（道具自动触发），原有操作不变。

数值配置集中在 tetris_defs.gd 常量区（刷新间隔 20s / 首刷延迟 15s / 碎片时限 15s / 雨上限 10 格 / 粒子参数），便于调参。

5. 技术方案（增量）

scripts/tetris/
├── tetris_defs.gd        + 道具枚举/颜色/数值常量
├── board.gd              + clear_rows_at(rows)      风:指定行整行移除(上方下移)
│                         + clear_random_cells(n)    雨:返回被消坐标列表
│                         + clear_columns(cols)      雷:指定列清除(不下落)
│                         + random_filled_cell()     碎片格选点
│                         + filled_row_indices() / filled_column_indices()
├── tetris_game.gd        + 碎片格状态机(idle/armed/countdown)
│                           道具自动触发流程(获取→ITEM_FX 预闪→执行)
│                           ITEM_FX 状态(0.35s) + 粒子事件驱动 + 浮字
├── board_view.gd         + 碎片格高亮绘制(金色脉动+倒计时环)
│                           道具选中行/列/散点的高亮预闪
├── particle_layer.gd     新增:粒子系统(数组池 + _draw + _process 更新)
└── piece_preview.gd      不变
  • 粒子层挂在 BoardView 同级（棋盘坐标系内），只依赖注入的数据事件， 与游戏逻辑解耦：game 调用 particles.burst(cells, color, count)。
  • 道具触发流程：消行带走碎片格 → 随机道具 → ITEM_FX 预闪动画(0.35s) → board 清除 + 粒子 burst + 计分 + 浮字 → 回到 PLAYING。
  • 风的整行移除直接复用 remove_rows（它本就支持任意行集合）；雨/雷为 原位置清除，不触发下移。
  • 存档不变（hi_score 延续）。

6. 边界与异常场景汇总

场景行为
刷新时棋盘无堆叠推迟选格，计时器顺延（不消耗本轮刷新）
碎片格所在方块被"雨"散点消除（非整行）不判定获取（仅整行消除算）；碎片格所在格被清空后直接熄灭等待下轮（避免复杂追踪）。注：自动触发模式下道具执行时碎片格必已熄灭，此场景仅存在于理论时序
道具目标不足（如风无可消行）道具作废，浮字「数据丢失…」，不产生清除效果
暂停 / Game Over碎片格计时冻结；ITEM_FX 动画冻结
重开局碎片格、计时器全部重置
ITEM_FX 动画期间按移动/旋转输入缓存忽略（0.35s 很短，可接受）

7. 里程碑与验收标准

里程碑

阶段内容
P1 道具核心board 三种清除方法 + 碎片格刷新/判定 + 自动触发流程 + 浮字 HUD
P2 粒子系统particle_layer + 普通消行粒子 + 道具消除粒子
P3 特效打磨碎片格动画/倒计时环、三道具专属演出

验收标准

  1. 开局 15s 后棋盘出现碎片格（金色脉动），15s 内消掉其所在行自动触发随机道具，超时熄灭。
  2. 风：随机 2 行整体消除且上方下移；雨：随机 ≤10 格散点消除；雷：随机 2 列清除成竖井； 三者消除后其余方块位置不变（雨/雷不下落）。
  3. 道具消除按 5 分×等级×格数计分，LINES 不变。
  4. 目标不足时道具作废并浮字提示；获取与触发全程无按键操作。
  5. 普通消行与道具消除均有粒子飞溅；获取道具有金色爆发与浮字。
  6. 暂停时碎片格计时冻结；重开局道具状态全部重置。
  7. 无报错、无脚本警告；帧率稳定（粒子峰值不掉帧）。
确认记录（2026-09-08）
  1. D2 已确认：获取后自动触发（无道具槽、无按键）。
  2. D4 维持默认：道具消除不计 LINES、按 5 分×等级×格。
  3. 数值（刷新 20s / 首刷 15s / 碎片时限 15s / 雨上限 10）集中在常量，可随时调。
