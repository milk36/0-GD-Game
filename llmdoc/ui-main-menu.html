游戏大厅主菜单 UI

主菜单是整个项目的入口场景，展示可选的小游戏列表。当前为纯 UI 框架， 点击任意游戏会显示「开发中」提示，各游戏逻辑待后续实现。

文件清单

文件职责
res://scenes/main_menu.tscn主菜单场景（已设为项目主场景 application/run/main_scene）
res://scripts/main_menu.gd菜单逻辑：绑定按钮点击、更新状态提示文字
res://themes/main_theme.tresUI 主题：Button 三态样式（normal/hover/pressed）与 PanelContainer 面板样式

场景结构

MainMenu (Control, 挂载 main_menu.gd, theme=main_theme, 锚点 full rect)
└── UILayer (Control, full rect)
    ├── Background (ColorRect #12141f, full rect)
    └── Center (CenterContainer, full rect)
        └── Panel (PanelContainer, min width 400)
            └── Margin (MarginContainer, 上下 32 / 左右 40)
                └── List (VBoxContainer, separation 12)
                    ├── Title (Label 「游戏大厅」 36px)
                    ├── Subtitle (Label 「选择一个游戏开始」 15px 灰色)
                    ├── Sep (HSeparator)
                    ├── SnakeButton / TetrisButton / G2048Button / BreakoutButton / MineButton
                    │   （贪吃蛇 / 俄罗斯方块 / 2048 / 打砖块 / 扫雷，高 46px，字号 18）
                    └── StatusLabel (点击反馈文字，绿色 14px，默认为空)

脚本逻辑（main_menu.gd）

_ready() 遍历 List 下所有 Button， 把点击信号连接到 _on_game_selected 并绑定按钮文字作为参数； 点击后 StatusLabel 显示 「<游戏名>」开发中，敬请期待~。 新增游戏时只需在场景里加一个 Button，无需改脚本。

后续接入真实游戏

为各游戏创建独立场景（如 res://scenes/snake.tscn），在 _on_game_selected 中用 get_tree().change_scene_to_file() 跳转，并在游戏中提供返回大厅的入口。
