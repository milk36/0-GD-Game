3. 关键实现决策

  • 渲染全自绘:棋盘 220 格 + 辉光多层描边全部 CanvasItem._draw(), 无节点开销、不依赖 Bloom(GL Compatibility 下表现稳定)。
  • 棋盘 22 行 = 20 可视 + 2 隐藏:锁定块整块落在隐藏区判 lock-out 负; spawn 位于 row 0-1,出生即碰撞也判负。
  • 简化墙踢:旋转失败依次尝试 原位 → 左1 → 右1 → 上1;O 块禁旋转。
  • 锁定延迟:触底 0.5s,移动/旋转可重置计时(上限 15 次)。
  • DAS:首次立即移动,按住 0.16s 后以 0.045s 间隔连发。
  • 最高分:user://tetris_score.dat(int64)。
  • 输入:8 个 tetris_* InputMap action(方向键 + WASD + 空格 + X/Z/C/P/Esc), 写入 project.godot。
  • 窗口:1280×720(棋盘 32px 格 × 10×20)。

5. 已知注意点(踩坑记录)

  1. GDScript 类型推断:遍历无类型数组(如 SHAPES)时 := 无法推断, 必须显式 var gx: int = x + c.x;调用 RefCounted(board) 的方法返回值同理(var grounded: bool = ...)。
  2. 跨脚本引用注入:tetris_game._ready() 必须执行 board_view.board = board,否则幽灵块计算在 Nil 上崩溃 (首版遗漏此行导致 debugger break,已修复并加 null 保护)。
  3. menu 内 UI 路径:覆盖层按钮在 _ready() 用绝对路径连接信号, 场景节点改名需同步 @onready 列表。
  4. Godot 4.7 无全局 fract()(Parser Error: not found in base self), 取小数部分用 fposmod(x, 1.0) 或 x - floorf(x)。
  5. 静态类型变量调用脚本方法会编译失败:var bv: Control 后调 bv.show_item_fx() 报 not found;需去掉类型标注(动态派发)或 as 到具体脚本类。

7. 道具系统与粒子特效(2026-09-08 增量)

需求与设计决策详见 tetris-items-design.html(D2 已确认:获取后自动触发)。

7.1 实现结构

scripts/tetris/
├── tetris_defs.gd    + Item 枚举、道具颜色/名称、数值常量(首刷15s/间隔20s/时限15s/雨10格)
├── board.gd          + random_filled_cell / filled_row_indices / filled_column_indices /
│                       all_filled_cells / collect_row_cells / collect_column_cells / clear_cells
├── tetris_game.gd    + State.ITEM_FX;碎片格刷新计时/存活倒计时;_acquire_item →
│                       _select_item_targets →(0.35s 预闪)→ _execute_item;浮字
├── board_view.gd     + 碎片格金色脉动框+倒计时弧;风行条带/雷列光柱/雨散点格预闪
└── particle_layer.gd 新增:纯数组粒子系统(重力+阻尼+淡出,上限3200,挂 BoardView 下)

场景新增:BoardView/Particles(粒子层)与 /Tetris/FloatLabel(道具浮字)。

7.2 关键行为

  • 碎片格只选已填充格子;棋盘空时刷新计时顺延(1s 重试)。
  • 获取判定在 _finish_clear:碎片格所在行被普通消行带走即触发; 未被消则行号随下移自动修正。
  • 风/雷均从非空行/列中选目标(雷从非空列选,避免稀疏棋盘高作废率—— 首版从全部 10 列随机导致约 62% 作废,已修正);雨从全部填充格随机 ≤10 个。
  • 雨/雷清除后其余方块不动(无逐格重力),留下孔洞/竖井;风复用 remove_rows 整行下移。
  • 道具消除不计 LINES,按 5 分×等级×格数计分;目标不足道具作废(浮字「数据丢失…」)。
  • 暂停恢复使用 _paused_from 记忆(修复了从 CLEARING/ITEM_FX 暂停后 错误恢复到 PLAYING 的状态机缺陷)。

7.4 欢乐模式(2026-09-08 增量)

  • 入口:大厅「俄罗斯方块·欢乐模式」按钮;通过 tetris_defs.gd 的 static var fun_mode 传参(菜单点击时写入,tetris _ready 读取), 两个入口共用同一场景文件。
  • 模式参数表 DEFS.ITEM_PARAMS:标准(首刷15s/间隔20s/时限15s/并存1格) vs 欢乐(首刷5s/间隔6s/时限10s/并存3格)。
  • 碎片格改为多格数组(item_cells: [{cell, life}]),逐格独立倒计时、 各格脉动相位错开;新格不与现有格重叠。
  • 道具队列 item_queue:一次消行带走多个碎片格 → 多个道具入队依次连发; 风的整行消除也可带走其他碎片格(道具滚道具);队列中无目标的道具自动跳过作废。
  • 左栏 ModeLabel 显示当前模式(欢乐=粉色 ⚡ FUN MODE,标准=灰色)。

验证:多格上限/唯一性/视图同步、双道具队列连发(其一执行后清空棋盘、其二自动作废)、 标准模式回归(单格/15s/标签)全部通过。

7.5 道具专属使用特效(2026-09-08 增量)

实现需求文档 3.2 节的三道具专属演出(此前仅有统一色块高亮):

tetris_defs.gd     + ITEM_WIND_HL_TIME(0.15) / ITEM_BOLT_ZIG_TIME(0.2) / ITEM_RAIN_STEP(0.03)
board_view.gd      + _draw_wind_fx: 行高亮(0~0.15s) → 左右两条速度线横向扫过(头部亮/3段渐隐)
                   + _draw_rain_fx: 散点格按 30ms 逐个蓝白闪现 + 已闪格上方循环坠落雨滴指示线
                   + _draw_bolt_fx: 锯齿电光自顶向底扫描(0.2s,黄粗白细双层+头部亮点) → 整列闪白
                   + _gen_zigzag: 每列预生成 3 条锯齿折线,绘制时按进度轮换(电光抖动感)
particle_layer.gd  + 粒子结构增加 kind(dot/trail) 与 grav(重力系数);trail=沿速度方向拖尾线
                   + wind_streaks_row(行内横向高速风痕,免重力) / rain_drops(自上坠落蓝白雨滴)
                   + bolt_arcs(列内随机高度黄白电弧)
tetris_game.gd     + _execute_item 消除瞬间按道具调用对应粒子接口
  • 预闪动画全部由 fx_progress 驱动(不再读 Time.get_ticks_msec()), 暂停 / Game Over 时 progress 不更新 → 演出天然冻结,符合设计决策 D5。
  • 锯齿电光与风痕均在 ITEM_FX_TIME=0.35s 内分阶段完成,数值集中在 defs 可调。
  • 验证:三类预闪逐一定格截图通过(风痕扫过/雨滴逐格闪现/锯齿电光+列闪白); 三种拖尾粒子经运行时同帧落盘截图确认(方向/配色正确);全程无脚本报错。

7.6 道具进化与新道具(2026-09-09 增量)

道具系统深化第一期为 5 种基础道具 + 3 种进化版(设计决策见 tetris-items-design.html 的扩展记录):

tetris_defs.gd     + Item 枚举扩至 8 种;BASIC_ITEM_COUNT=5(随机池);
                   + EVOLVE_MAP(相邻同类合并:风风→飓风/雨雨→暴雨/雷雷→雷暴);
                   + STORM_WIND_ROWS=3 / TORRENT_MAX_CELLS=20 / THUNDER_MAX_COLS=3

board_view.gd      + FLIP 演出:中央对称轴 + 左右扫描线向中轴收拢 + 扫过半区微光
                   + PRUNE 演出:目标格同时绿高亮 + 格顶 V 形刀光
                   + 进化版复用基础演出(_draw_item_fx 内 visual 归一化)
tetris_game.gd     + _enqueue_item:入队时与队尾同类基础道具合并进化(翻转/削峰不参与);
                   + FLIP 执行:镜像棋盘与碎片格坐标,当前块碰撞时向上抬升寻位(≤5 格,
                     找不到判负);零消除零分,附硬降同款震动
                   + PRUNE 执行:clear_cells(peak_cells),计分走通用 5×等级×格
  • 随机分布:基础 5 种等概率(风/雨/雷/翻转/削峰);进化版只能由合并产生。
  • 进化版浮字独立命名(STORM · 飓风撕扯 / TORRENT · 暴雨倾盆 / THUNDER · 雷暴降临)。
  • FLIP/PRUNE 暂无专属施放音效(PRUNE 消除走 item_clear,FLIP 用震动反馈),待补音色。
  • 验证:headless 测试场景 8 项断言全部通过(进化链/FLIP 镜像/PRUNE 执行/ 空盘作废/随机池覆盖/三个进化版目标数);FLIP 与 PRUNE 演出定格截图确认。
